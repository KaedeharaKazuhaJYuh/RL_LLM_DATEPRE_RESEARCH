# FaultDA-Bench 0.2.60-dev · 真实模型诊断前的协议冻结

日期：2026-10-11。已准备 DeepSeek 入口，完成公开可靠性契约、九条件固定计划、36 条程序对照和网络替身测试。**真实 API 调用为零，没有新的模型成绩。**

## 工程完成

- 同一公开说明明确原始输入与版本目录可信，报告/暂存计算可能共同出错；隐藏具体故障 mode 与答案。
- 四条规则和未来模型共用 JSON 观察边界；每次记录标准公开提示的哈希及字节数，能重建核验，不把私有任务对象交给策略。
- 模型接口固定 JSON 动作、96 次全局尝试上限、单次 max_tokens=800、45 秒超时和零隐式重试。超预算、非法输出、限额与服务错误分别记账。
- 后续真实调用记录实际 model、可用 usage 与 response_id，按完成条件落盘；未知 token 不写成零，模拟 transport 不登记为真实供应商成绩。
- 离线结果与未来真实结果使用不同 backend，核验不再次调用模型，也不声称能认证供应商响应来源。

## 离线对照

每臂九条条件，来自三个旧实例 × 三种工具计算模式：

| 程序策略 | 安全完成 | 虚假完成 | 安全升级 | agent 错误发布 |
| --- | --- | --- | --- | --- |
| 读取参考 | 6 | 3 | 0 | 3 |
| 暂存参考 | 3 | 6 | 0 | 3 |
| 数值守卫 | 6 | 0 | 3 | 0 |
| 直接升级 | 0 | 0 | 9 | 0 |

结果与上一轮对应条件一致；新增可靠性文字尚未在真实模型上测量，不能推断提示改写有因果提升。规则的程序计算属于系统帮助，不是等成本 LLM 能力。

## 验证与边界

全仓库 189 项测试通过。统一入口固定 94 份证据文件，全部 36 条新轨迹连同公开提示哈希重放通过。专项测试验证初始观察跨故障相同、实际请求消息与公开构造器相同、非法输出不自动修好、请求上限无重试、异常原文不入日志、模型超预算不被掩盖、模拟限额轨迹可重放，以及重算哈希后的提示篡改拒绝。

旧模块、签字与结果保持原样。新协议未独立人工审阅，科学 HOLD 不变。真实 API 连通性、实际模型行为与供应商 usage 仍待执行诊断；不是已经跑过 DeepSeek。接口规范核查见[协议](../docs/MODEL_PILOT_V11_PROTOCOL.md)中官方来源。
