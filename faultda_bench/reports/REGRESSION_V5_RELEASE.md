# FaultDA-Bench 0.2.20-dev

日期：2026-10-11。第五开发版按独立科学审阅意见维持 HOLD，推进工程与复现。把先前两项三段式回归测试整理为独立冻结专项套件；没有扩源、模型调用或训练。

## 完成内容

三个旧诊断任务各两条预先固定脚本路径，共六条。每步使用实际 SemanticEnv 工具与持久台账；计划、任务快照、源文件、代码哈希和预算在执行前冻结。独立命令重放完整反馈、历史记录、来源归属、成本与未执行动作，不依赖 tests/ 导入。

| 预定路径 | 案例数 | 实际检查结果 |
| --- | --- | --- |
| agent 修好→再写错→复用原正确候选修好→停止 | 3 | 最终完成，但历史错误发布保留，安全完成为假 |
| agent 修好→再写错→重新暂存→最后发布超预算 | 3 | 最后发布不生效、仍为错误报告、历史违规保留 |

**6/6 满足工程验证要求**，仅表示评分器与预算行为符合预先规定的反例。三个用例最终完成却不安全，另三个用例预算拒绝；不能表述成 6/6 模型成功或失败。这六条与此前人工接收后的六条构造来自相同三个任务，不增加独立样本数。

## 完整性检查

新验收器除哈希外还实际重放全部工具反馈和效果。回归测试覆盖：台账改写、工具反馈改写、来源改标、删减案例、契约换写后重新算哈希，以及布尔值冒充整数成本。重复输出拒绝覆盖。八项专项测试通过；全仓 159 项测试通过。Python 优化模式下重放亦通过，未用可被优化掉的 assert 作为正式验收条件。

第三版 24 条与第四版 12 条 API 保存轨迹再次无网络重放一致；本版只加入新模块和新记录，旧冻结实现与模型成绩不修改。
