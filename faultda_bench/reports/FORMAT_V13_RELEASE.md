本轮在相同三个初始公开快照上，关闭推理两档预算均返回合法外层动作。开启 low、800 的一次失败由供应商明确标记 length；开启 low、2048 的四次 JSON 失败均标记 stop。因此格式失败可以发生在未被标记截断的返回中，增加输出预算在这批记录中未带来更高合法动作数。未保存正文，不能判定这四次 JSON 失败的具体文本原因，也不能证明模式参数是唯一因果来源。

供应商报告模型 deepseek-flash；输入 18,420 token、输出 5,381 token，合计 23,801。未核验账单金额。与上一轮多步自适应轨迹的消耗不能直接比较为效率提升。24 次请求只覆盖三个初始快照，每配置每快照两次；不是 24 个独立任务，没有执行恢复动作或训练 RL。
