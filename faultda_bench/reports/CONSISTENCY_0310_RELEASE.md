# 0.3.10-dev：公开证据一致性检查收尾

本版完成结构化检查器及冻结响应的配对离线复核。没有新增 API 调用、模型修订回答或多步干预；不能将拒绝错误记录视为模型提升。科学状态 HOLD，新增范围待独立复审。

## 结果

复核 0.3.05-dev 的八条 normalized 响应：内部一致性与原始公开数据绑定检查均拒绝六条，保留两条。错误是 UTC 时间事实与比较标签矛盾。检查器没有修复答案，也没有改变历史评分、发布事件或终态。

六个工程反例全部满足预期。尤其整体平移时间、同时篡改数值与总和能通过内部自洽检查，却被公开数据绑定拒绝。这说明内部自洽不能替代来源核验；属于预设程序反例，不是新科研机制。

## 边界

仅支持明确时区、唯一行 ID 的窗口记录；缺失值用 null，不参与求和。输出显式零偏移 UTC，布尔字段必须是真布尔，非有限数、重复 ID、模式错误拒绝。绑定输入必须来自已授权的公开契约、版本目录及原始行；输入可信是前提。本版未实现提交守卫、并发状态推断、历史副作用自动修复或在线停止策略。

冻结结果保留原始响应索引及旧评分。检查器不读取私有评分器；离线运行器只引用旧评分作核对。八条记录仍是一个任务簇，不能当八个独立任务。两类检查同一记录配对，不宣称成本相同或统计显著。
