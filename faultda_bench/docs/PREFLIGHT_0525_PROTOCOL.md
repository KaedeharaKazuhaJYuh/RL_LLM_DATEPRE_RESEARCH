## 发现与处理

0.5.20 的 actor 视图要求调用方显式给出 query 与目标 publish。旧资格核对从参考字段取得目标。这在该批唯一请求历史中能由公开信息等价推导，**没有因此证明旧实跑发生答案泄漏**；但它不能原样充当未来“没有额外帮助”的模型比较入口。

新增 `review525.preflight.resolve(observation, query_event_id)` 仅接受公开观察及显式查询事件。它扫描查询之前同 request_id 的 publish，不读取参考目标、私有账本、案例模式或来源匹配注册表；同请求多次尝试继续返回歧义，不猜责任。快照必须结束在该查询，不能无声借助后续动作。顶层公开字段与返回回执字段采用白名单，拒绝额外参考字段；不提供 stop/违规答案、来源认证或回执真实性认证。

旧 72 条脚本观察的公开推导均与旧参考一致。参考只在可信核对程序拿到解析结果后比较，绝不送进解析器。它们是读取后的旧快照，不是新任务初态，不具有新独立性，也不构成模型重评分、恢复执行或能力提升。

## 比较前置校验实际保证什么

新增 `compare_setup` 拒绝两臂案例删除、观察替换、工具权限不同、工具预算不同、预处理代码/视图不同、未计费的外部帮助及声明的私有真值访问。工具还必须出现在每个案例的公开工具列表中。

相同工具上限单列 checks、mutations、decisions、response_bytes、wall_seconds；预处理绑定代码摘要、视图 schema 和计费声明。这里只检查声明一致，**不认证执行器确实遵守、不证明预算可完成、不保证所有计算帮助公平、不等于实际总成本相等**。模型 token/程序 CPU、时延及费用须在真实执行后分列，不能由配置相同推断相等。未知血缘和独立资格也不会被这个函数批准。

测试中的双臂配置是合成夹具，不能拿来当旧快照可执行的预算方案；真实比较计划仍为 0。字段白名单不是任意内容的机密分类器，公开字段的真实性和独立审阅仍需可信来源；本轮不声称完成全系统信息流或运行时权限审计。
