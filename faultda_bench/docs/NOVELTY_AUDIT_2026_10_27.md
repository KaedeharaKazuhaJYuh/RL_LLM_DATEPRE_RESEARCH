# 近邻查新审计（2026-10-27）

**2026-10-28 更正：**“近邻只把检查成本当预算而没有定价”不成立。下文第 3 节补充 CostBench、CAM-DF、ACL VoI 和已有价格干预；这些工作与本项目的状态和决策时机不完全相同，但足以排除“价格化工具决策本身是空白”。本比较为有界文献核对，不是穷尽式查新或对作者实验的独立复现。

范围：原审计为 2026-06 至 2026-10-27 的 arXiv 公开成果，检索工具为 WebSearch（快照日期 2026-10-27）；2026-10-28 补充了较早的直接价格研究。目的是对照研究设置及现有证据，而非穷尽式文献综述。

现有工作与判断后仍调用、证据到动作、监督与 RL 对照均存在密切重叠；任务、对照和指标并不完全相同，实验规模本身也不能决定新颖性。目前没有证据证明本项目在这些方向上具有非平凡的独立增量，不能仅凭措辞变化或扩大样本声称创新。

## 2. 三条必须承认的判断

**一、V5.0.15 的 0/240 不能写成"RL 失败"。** 报告自己第 1 条已经写了：初始适配器并非已掌握 A/B/C/D 四分类的模型，起点 0/240 不代表历史能力；branch 臂只训首动作、后缀仍由当时策略采样，与 SFT/GRPO 的更新目标不同源。2606.26027 给出的是控制 token 概率尖峰这类可实现机理解释。当前证据更支持"这个适配器没学会恢复接口"，而不是"RL 不行"。

**二、V5.0.05 的匹配监督对照是正确设计，但结论已被更早、更大规模地发表。** 2609.17848 覆盖 6 个模型规模，SFT 在 15/18 设置最强。本项目的三种子、144 题对照只能作为独立复现，不能作为主张。

**三、V3.5 的"日志保真度是瓶颈"与 2610.21098 冲突。** 本项目的观测是 480 条恢复案例中 5 个错误全部落在截短日志（85/90，截短 17/22 vs 其他 68/68）；2610.21098 在固定任务上扰动返回记录编码，效应小且校正后不显著。两者不一定矛盾（操纵的变量不同：一个是日志截短，一个是记录编码），但在写成主张之前必须做一次同构对照，否则审稿人会直接引 2610.21098 否掉。

## 3. 直接价格研究与本项目边界（2026-10-28 修订）

| 直接近邻 | 其原文已经做什么 | 与 VeriCost 的区别及当前判断 |
|---|---|---|
| [CostBench](https://arxiv.org/html/2511.02734v1#S3) | 向模型提供可调整的工具价格，比较替代路径，并在价格变化或工具受限时考察重新规划；使用最优路径参照。 | 它主要研究工具路径与动态成本；本项目的开发环境突出分析状态与检查后果，但尚未在外部模型实验中证明该差别改变结论。 |
| [CAM-DF / Scores Are Not Decisions](https://arxiv.org/html/2607.27083v1#S3) | 对工具获取设置异质成本和效用，按停止与继续的价值差训练停止决策；有 regret 相关理论和真实执行验证。 | 其选择发生在执行前的排序工具前缀；本项目的检查发生在有状态执行中。时机不同，但“价格化停止”或“regret 分解”本身都不是空白。 |
| [ACL 2026 VoI](https://aclanthology.org/2026.acl-long.1987/) | 比较向人提问的信息收益与认知成本，设计风险敏感的决策框架。 | 人机澄清与工具检查不是同一操作，但都不能忽略已有的信息价值和成本权衡。 |
| [Judged Useless, Queried Anyway](https://arxiv.org/html/2610.06191v1#S4) | 在提示中提供每次调用价格；附录也用多个价格重计既有轨迹效用并比较简单停止策略。 | 固定价格提示、事后重计与针对多个价格的真实行为干预需区分，不能声称该文没有价格分析。 |

VeriCost 的 C1–C5 证书只在明确的有限环境、动作、先验与效用模型下支持计算最优参考；外部环境的部分可观察状态和真实价格下，能否求出同等参考尚未建立。两个价格点上分别训练或选择的策略也不能直接给出同一 Agent 的因果价格弹性。

目前只保留一个待检问题：在相同任务、可见信息和工具权限下，公开价格如何影响**实际检查行为及净效用**，相对可执行强规则是否呈现近邻尚未解释的差异？这是研究候选，尚无实证增量。不能由价格设定、证书或变量组合本身推断原创性；应先核查[外部试点设计](../../research/reliability_reset/EXTERNAL_PRICE_PILOT_2026_10_28.md)是否可行、原生评分能否独立保留以及参照策略是否公平，再决定模型执行。
