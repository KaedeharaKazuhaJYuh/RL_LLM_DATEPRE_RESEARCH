## 研究定位决策

原先“相同超时消息 + 查状态 + 避免重复提交”的核心与 UndoBench、Verified Tool Calls 明显重叠。本轮把该原型降为**对照机制复现与评分器验证**，不宣称首次或已通过创新性门槛。

保留三个需要进一步检验的候选问题：

1. 数据分析中，**已提交与分析正确是两个维度**：列绑定、缺失值、行序或聚合定义错误仍可能持久提交。研究终局语义契约与提交状态查询共同作用；必须与已有 semantic-effect oracle 比较，不能认为换成 CSV 就自然新颖。
2. **合法检查有成本且可能不可用**：构造全程不可辨的状态对，评测适当升级、过度拒绝与任务完成覆盖率；先核查上述工作是否已完整包含同类决策问题。
3. **Controlled-binding 与 Autonomous-binding 的差别**：让模型真正读取 schema、参数和数据观察，定位规划/绑定错误与恢复错误，按独立来源及意图簇统计，不靠复制来源来增加样本数。

当前 P0 科学退出门槛仍未达成：已有可运行的风险探针，但尚未证明其相对最近研究有非平凡增量。下一步先完成 UndoBench/Verified Tool Calls 的接口、任务、可观察性、指标与许可证逐项核查，再决定是否扩大至六来源 alpha.1。若覆盖基本相同，依用户协议 §12.2 收束或转向，不强行扩题量。
