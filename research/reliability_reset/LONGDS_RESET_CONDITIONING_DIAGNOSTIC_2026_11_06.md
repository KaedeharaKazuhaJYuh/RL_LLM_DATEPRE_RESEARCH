# LongDS 重置效应：基线结果条件化诊断

日期：2026-11-06

## 当前结论

**[事实]** LongDS-Bench §5.3 / Appendix C.7 比较 persistent baseline 与 reset 在相同重置后轮次的准确率；排除 5 个持续基线几乎全错或只答对一轮的任务；从第 2、4、6、15 轮候选中按 persistent accuracy 选择重置轮；并按这些重置后轮次上的 persistent accuracy 将任务分成 Low/Medium/High。

**[推断]** 以对照运行的同一结果 `P` 分组，再比较 `R-P`，可能让低 `P` 组显得改善、高 `P` 组显得退化，即使重置策略没有真实平均效果。这是基线结果条件化/回归均值的经典风险。由于我们没有该论文逐任务、逐轮的两臂原始分数和随机种子，不能据此断言 LongDS 结果有偏。

**[待补]** 逐任务两臂原始分数、重置轮、重复运行/种子、任务排除细节，以及模型运行结果。

## 解析诊断（合成假设，不是 LongDS 数据）

令无真实干预效果：基线分数 `P` 与重置分数 `R` 都围绕同一潜在能力 `μ` 波动，标准差相同为 `σ`，相关系数为 `ρ`。假定两者联合正态，则：

`E[R − P | P = p] = (ρ − 1)(p − μ)`

因此，只要重复运行不是完全相关（`ρ < 1`），按低/高 `P` 分层就会机械地产生方向相反的组内差值。标准化后，以 `P ≤ μ−0.5σ` 和 `P ≥ μ+0.5σ` 分组，截断正态分布的组均值距总体均值约 `1.141σ`：

| 两次运行相关系数 ρ | 低基线组表观差值 | 高基线组表观差值 |
|---:|---:|---:|
| 0.50 | +0.571σ | −0.571σ |
| 0.80 | +0.228σ | −0.228σ |
| 0.95 | +0.057σ | −0.057σ |

这些数值仅由上面的合成正态模型解析计算，不是实测分数、效应估计或对 LongDS 的复现。真实任务分数是有限轮次的离散准确率，任务异质性、配对相关性及重置时点选择都会改变数值。

## 研究问题的最小重构

不问“重置是否帮助弱状态”，改问：

> 在真实多轮 Agent 任务上，按对照后续准确率分层与按重置前独立状态诊断分层，是否会给出不同的恢复策略效应和策略选择？随机化重置时点后，这种差异是否仍会改变跨任务的策略排序？

- **主要结果：**各策略在冻结完整任务上的逐任务平均原生分数和任务完成率；按预先定义的重置前状态分层的配对处理效应。
- **关键诊断：**复现论文式 persistent-outcome 分层，比较差值与策略排序；报告全部 24 个任务以及排除任务敏感性，不把分组轮次当独立样本。
- **基线：**persistent、随机指定时点 reset、固定规则时点 reset；若能实现，加入状态重建策略。所有策略同模型、任务、预算和评估器。
- **关键设计：**重置时点在运行前随机化；状态质量由重置前独立检查结果定义；多次重复按任务配对；预注册纳入、缺失和统计分析规则。
- **否证：**若预处理分层、随机时点与论文式分析给出相同结论和策略排序，或变化只来自缺失/评分口径，则该候选关闭。

## 新颖性与可行性判断

**[事实]** LongDS 本身已经研究 reset/persistent trade-off；一般的基线条件化、回归均值和预注册分层是成熟统计问题。已有实验结果的仓库树中未发现逐任务重置结果文件；论文正文只足以恢复方法描述，不足以复算原结论。

**[推断]** 单独指出回归均值不是独立论文贡献。只有当真实 Agent 重跑显示：结果条件化的分层/时点选择会稳定地改变恢复策略排名、基准结论或实际策略选择，并且该影响不能由已有 agent-evaluation / causal-methods 工作解释，才有进一步论文价值。否则应将其作为 LongDS 结果解释的敏感性注记，不单独投稿。

**决定：HOLD；不运行模型 API，不下载底层数据，不声称 LongDS 结论错误。** 当前证据已把候选推进到可直接否证的设计，但未证明项目已有独立科研贡献。

## 2026-11-06 版本更新后的可复核性补查

**[事实]** LongDS 官方数据卡现列出 v1 与 v1.1 的 Full（68 个任务、2,225 轮）及 Lite（24 个任务、777 轮）；v1.1 修订任务范围、并列规则、输出约定和继承状态语义，官方建议新评测优先使用 v1.1 Lite。官方说明不同版本的结果不应直接互换。v1.1 任务沿用输入数据，但任务规格位于独立版本目录。来源：[官方数据卡](https://huggingface.co/datasets/zjunlp/LongDS)。

**[事实]** 官方 LongDS 仓库 README 将新版 v1.1 Lite 排行榜与论文原始实验分开：新版分数来自各自原生 Agent 框架；原论文的长程退化图与 reset 分析仍代表原实验设置。README 的复现结果目录说明单次新运行可写出逐轮 `results_eval.json`，但公开仓库树中的结果相关文件是汇总图、排行榜图和运行器代码；本次公开树清点未发现论文 reset 实验的逐任务分数表、运行日志或重复种子记录。来源：[官方仓库 README](https://github.com/zjunlp/DataMind/blob/main/longds/README.md)、[仓库文件树](https://github.com/zjunlp/DataMind/tree/main/longds)。

**[推断]** v1.1 提供了一个版本明确、可由官方 runner 产生逐轮分数的后续验证入口；它没有补齐旧论文 reset 分析的原始数据，也不能由新版聚合榜单反推 reset 效应。v1.1 任务语义经修订，旧 v1 结果不得无条件移植到新版本。LongDS 论文候选仍 **NO-GO 作为当前独立论文主张**；版本更新只让未来的受控复现实验更可操作，不构成实证或新颖性证据。

**后续准入条件**：若重新评估该问题，必须固定 v1.1 版本、完整使用 24 个任务而不是只挑显著任务；重置时点在观察未来结果前随机分配；状态质量由独立的重置前测量定义；持续、重置与状态重建策略使用相同任务、模型/Agent、工具权限及成本口径；保存逐轮原始输出、评分、状态快照、随机种子和排除原因。只有与原论文式 outcome-conditioned 分层相比，独立前置分层能在冻结任务上稳定改变策略选择，且该差异超过成熟统计/恢复方法近邻的解释范围，才重新打开独立贡献审查。否则不复活该候选。

本次只检查公开数据卡、README 与文件清单；没有下载 LongDS 任务/竞赛数据，没有运行模型、API 或测试，也没有把公开排行榜数值当成本项目实验结果。
