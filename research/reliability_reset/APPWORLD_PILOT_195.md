# 1.0.95：真实模型接入与计费记录试点

记录日期 2026-10-30；模型试跑发生于 2026-10-29。该版验证真实模型能否在原生环境内产生可复核轨迹，**不是**跨任务实验、论文结果或 RL 效果提升。原生评分漏判率和独立违规标签仍未知，科学状态 **HOLD**。

## 设计与结果

使用 1.0.85 已研究过的 AppWorld 0.2.0 第一个 train 任务 `82e2fac_1`；它不是未见任务。两种模型在分别启动的原生环境中接收相同初始任务、公开应用描述和结构化 API 接口；每条轨迹至多 8 轮、每次生成最多 256 token。仅允许模型选择公开文档中的 API 及参数，不执行模型生成的 Python。原始错误提案保留，缺少参数或 API 不存在时不会自动修补。

| 条件 | 模型轮数 | 记录到的工具请求 | 提案拒绝 | 完成信号 | 原生完整评分 |
| --- | ---: | ---: | --- | --- | --- |
| 不执行动作的弱控制 | 0 | 0 | 不适用 | 否 | 1/2，失败 |
| DeepSeek Flash API | 8 | 4 | 4 次：缺少参数 2、未知参数 1、未知 API 1 | 否 | 1/2，失败 |
| 本机 DeepSeek-R1-Distill-Qwen-1.5B，CUDA | 8 | 0 | 8 次输出达到上限，未形成可执行提案 | 否 | 1/2，失败 |

这些是单个已见任务的技术样例：不能推断不同模型的能力排序，也不能推断有无违规。无动作只是弱控制，尚未满足强规则对照。模型的初始消息逐字节相同，但 DeepSeek 使用服务商的 JSON 模式，本地模型只依靠文本提示；两者 tokenizer 不同，且同属 DeepSeek 相关谱系，不能当作多个独立模型家族。

原生完整评分针对原始任务和未修改评分器；1/2 不能当作任务成功。三条运行分别在新的进程中对保存终态重新评分，均得到同样的 1/2；重放不增加任务或轨迹样本数。匹配官方数据包核验了 95 个初始数据文件，两个模型的首轮消息摘要一致。1.0.90 的 GPT-4o 数据使用 0.1.0、不同 Agent 与预算，不能与本试跑直接比较。

## 调用、费用与时间

DeepSeek 实际收到 8 个响应，提供商报告共 21,492 个输入 token，其中缓存命中 17,152、未命中 4,340；输出 264 个 token。按试跑前 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)的峰值费率计算约 **0.001721712 美元**，是用量估算，不是账单；优惠时段、账户折扣和计费规则可能不同。预先冻结的 8 轮与输入／输出上限对应峰值保守预留约 0.06252 美元，该预留也不构成账单保证。

每轮保存了完整提示消息、原始模型内容、提供方响应 JSON、用量、请求 ID、工具提案和返回内容。模型请求记录不包含认证头；两个原始日志按本机配置的 DeepSeek 密钥做过精确匹配扫描，未发现匹配。工具日志保存返回体，但**不保证包含底层 HTTP 状态码或未跟踪的所有内部调用**；真实账单、能耗和电费均未取得。

本地 CUDA 模型共生成 2,048 个 token，记录的生成时间合计 69.44 秒，峰值分配约 4.43 GB 显存；它与在线 API 的延迟不能直接比较。模型输出先保留原文，只有闭合的 `<think>` 前缀才会被分离后解析；截断输出不被补齐。

AppWorld 会将进程内日期和普通计时冻结到任务时间。预检实际复现了这一问题，随后调用 `freezegun` 保留的真实时钟记录请求时间及耗时；单独预检核对通过。另一项预检因 `agent` 包的间接 NumPy 依赖而未启动，改为直接加载现有配置模块，未修改历史 AppWorld 依赖环境。初次以不抑制断言模式评分无答案控制时抛出预期断言；使用官方用于记录失败的评分模式后得到 1/2。上述均为接口预检，不计入模型运行。

## NPU 与证据

Intel AI Boost NPU 可被 OpenVINO 识别，独立 ReLU 计算图在 NPU 上编译、执行并通过数值检查。现有三份 INT4 模型的 XML 文件均出现读取权限拒绝，因而此次没有完成 NPU 大模型推理；未改变文件权限，也不能把本次 NPU 结果与 CUDA 模型表现比较。

事先保存的本地试跑协议 SHA-256 为 `581165770cbb4658c3818dc0136fe8dd0639b35b7bfe9515801240a23ce2f9ae`。包括协议、受保护原始模型／工具记录、原生输出、复核摘要和 NPU 诊断的[加密证据包](evidence/1.0.95/appworld-pilot-1.0.95.bundle)共核对 65 个源文件；[收据](evidence/1.0.95/RECEIPT.json)记录包摘要。它遵循 AppWorld 受保护内容的加密再分发要求，但公开解密参数不提供保密性；哈希也不是独立历史认证。原始输入和基础数据库需另用官方 0.2.0 数据包。
