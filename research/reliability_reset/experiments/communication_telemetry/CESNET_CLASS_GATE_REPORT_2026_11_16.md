# 类别可靠性筛选：逐周开发结果

依据[事前一页设计](CESNET_CLASS_GATE_DESIGN_2026_11_16.md)，固定阈值 0.05，按每周已释放标签中各预测类别的样本量和 Wilson 数值筛选可用类别，再决定是否使用无标签伪标签；以同种子、同初始化的回放及未筛选伪标签为对照。

| 标签种子 | 周 | 筛选前无标签候选通过阈值 | 筛选后接收 | 允许的类别数 |
| --- | --- | ---: | ---: | ---: |
| 1 | W15 | 25 | 0 | 0 |
| 1 | W16 | 45 | 0 | 0 |
| 1 | W17 | 68 | 0 | 0 |
| 2 | W15 | 24 | 0 | 0 |
| 2 | W16 | 62 | 0 | 0 |
| 2 | W17 | 64 | 0 | 0 |

两个种子各周均回退到监督回放；W15–W18 共八个完整周预测文件与各自回放对照的摘要完全一致，标签行和候选行摘要也匹配。因此，筛选组的下游分数等于回放，并非无标签学习提升。未筛选臂的 W16–W18 分数明显较低，详见[低阈值结果](CESNET_LOW_THRESHOLD_SSL_REPORT_2026_11_16.md)；不能把避免退化的回退写成半监督方法优于回放。

门限的 Wilson 数值只是候选筛选启发式：流之间可能相关，已释放标签同时用于训练，且按类别进行了选择。它不提供真实流量覆盖率或类级精度保证。门限受先前开发数据启发；两个种子共享同一初始化和数据源，W15 已调试、W19+ 未使用。实际 gate 的标签预测与筛选计算增加成本，尚未严格测量增量能耗/FLOPs。类别筛选已有相关研究，这个开发结果不能建立独立论文贡献。
