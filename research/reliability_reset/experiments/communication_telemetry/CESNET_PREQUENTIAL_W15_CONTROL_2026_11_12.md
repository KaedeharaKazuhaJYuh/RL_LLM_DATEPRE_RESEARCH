# CESNET W15 前向评估流程：固定规则控制

对 2022-W15 的 195,033 条 XS 真实流，先用固定多数类规则生成预测、落盘并计算 SHA-256，再由评估器读取标签计算分数，最后用随机种子 20261112 无放回抽取 1,000 个标签。预测回调只接收无标签字段；真实标签只由评估器读取，供更新的返回值限于抽中的行。本流程为单进程可信调用者设计，回调若自行打开原始归档仍能获取标签，因此不是隔离沙箱，也尚未实现模型更新和跨周状态管理。

规则选择初始化期 W11–W14 中出现最多的类别；此处使用了该阶段**全部 1,086,644 条标签的聚合计数**和完整初始词表，未匹配少标签预算，只是工程控制。W15 准确率为 4.9433%，固定 180 类 macro-F1 为 0.0005234；抽取的 1,000 个标签覆盖 141 类。该值不代表训练模型的质量或 SNN 优势，也不用于论文性能主张。[机器记录](CESNET_PREQUENTIAL_W15_CONTROL_2026_11_12.json)

固定分类词表由初始化阶段 APP 类别构成，macro-F1 对全部固定类别等权，分母为零的类别记 0；词表外真实标签计入对应预测类的假正例，并单独报告数量。预测文件在本地保留，公布聚合结果与预测文件摘要，不提交逐条预测或标签。两个合成表测试覆盖标签在预测文件封存后读取、抽样不重复与相同种子可复现、跨周日期拒绝、mask/白名单及批次索引。依赖 NumPy 与 PyTables。

复算示例（需要指向本地 XS 归档和一个不存在的预测输出文件）：

```sh
python -m research.reliability_reset.experiments.communication_telemetry.run_cesnet_development_control <XS-HDF5> --prediction-path <new-predictions.npz> --summary-path <summary.json>
```

实现细节与完整流程见 [cesnet_prequential.py](cesnet_prequential.py)。模型、预算匹配、多周训练、门控、统计不确定性与外部复核仍未完成，科学状态 HOLD。
