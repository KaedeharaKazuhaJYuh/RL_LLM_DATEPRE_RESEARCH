# CESNET-TLS-Year22 XS 输入字段契约

日期：2026-11-10　｜　对应协议：[v0.2](COMMUNICATION_TELEMETRY_EVENT_DRIFT_GATED_SSL_PROTOCOL_V0_2_2026_11_10.md)　｜　状态：实现前契约，尚无模型结果

## 任务边界

当前任务定义为**完整流结束后的服务分类**，按周连续适配。每条流的 SNN 事件分支处理记录的前最多 30 个包；统计分支可以看到整条已结束 flow 的汇总。因此本协议不声称支持流尚未结束时的在线早期识别。若将来研究早期识别，必须重新构造只含当时可见前缀的统计字段，不能复用完整流汇总。

数据来自 2026-11-10 census 所固定的 Year22 XS schema，45 列、180 个实际 APP 标签。APP enum SHA-256 为 `71661ce0b59c4eb02b4001d4366cb49e4bc7cdf0131c6b23b972a4b069f240dd`，CATEGORY enum SHA-256 为 `c10c1e3cfdab459b20fc597ba8aa9dc662b654f9a41e486394e350dedc94d4de`。以下白名单基于固定 DataZoo 源码及完整 HDF 表结构；正式训练前，加载器仍须对列名和维度执行一次精确匹配。

## 输入与标签白名单

| 来源 | 列 | 用途 | 限制 |
|---|---|---|---|
| 包序列 | `PPI` | **事件视图**；固定通道顺序为 `IPT`, `DIR`, `SIZE`, `PUSH_FLAG`，长度最多 30 个包 | SNN 与匹配 ANN 接收相同原始张量；不把完整 HDF 行传入模型 |
| 包序列长度 | `PPI_LEN` | 只构造有效包 mask 和截断边界 | 不作为独立标量输入，不暴露被填充长度以外的标签线索 |
| 完整流汇总 | `BYTES`, `BYTES_REV`, `PACKETS`, `PACKETS_REV`, `DURATION` | **流摘要视图** | 当前任务在 flow 完成后分类；所有缩放器只用过去已允许的数据拟合/更新 |
| 完整流直方图 | `PHIST_SRC_SIZES`, `PHIST_DST_SIZES`, `PHIST_SRC_IPT`, `PHIST_DST_IPT` | 流摘要视图；提供无顺序的包长/到达间隔分布 | 作为有序 PPI 的非时序参照，不送入 SNN 事件编码器 |
| TCP 标记摘要 | 全部 `FLAG_*` 列：CWR/ECE/URG/ACK/PSH/RST/SYN/FIN 及其 `_REV` 方向列 | 流摘要视图 | 如与 PPI 的 PUSH_FLAG 重复，保留重复关系供消融记录，不事后挑选 |
| 流结束原因 | `FLOW_ENDREASON_IDLE`, `FLOW_ENDREASON_ACTIVE`, `FLOW_ENDREASON_END`, `FLOW_ENDREASON_OTHER` | 流摘要视图 | 仅完整流结束任务；需在结果中标注其潜在终止行为信号 |
| 监督目标 | `APP` | 180 个服务标签的预测目标 | 不得作为输入；标签映射固定于数据表 enum 并记录哈希 |
| 评估分组 | `CATEGORY` | 23 个较粗服务类别，用于分层报告/支持数审查 | 标签派生层级，不作为模型输入或测试期特征 |

## 禁止作为预测输入的列

| 列 | 原因 |
|---|---|
| `TLS_SNI` | `APP` 的标注来源链路；直接泄漏目标服务 |
| `ID` | 流标识；没有可迁移的流量语义 |
| `SRC_IP`, `DST_IP` | 匿名化/伪匿名端点仍可跨流关联并记忆网络实体 |
| `DST_ASN`, `DST_PORT` | 目的网络/服务端点捷径，可能将特定服务身份直接映射到标签 |
| `TLS_JA3` | TLS 客户端指纹，可能记忆应用/客户端实现身份；主实验先排除 |
| `TIME_FIRST`, `TIME_LAST` | 只用于时间切分、排序和分组；时间戳不得作为预测输入 |
| `PROTOCOL` | 本研究固定为 TLS 数据集元信息；不作为跨数据集可泛化特征，训练前仍核对实际取值 |
| `PPI_DURATION`, `PPI_ROUNDTRIPS` | 序列派生统计；主实验避免在事件分支中重复注入它们 |

上述分组覆盖原始 schema 的 45 列：事件张量 1 列、mask 1 列、统计分支 29 列、标签/分组 2 列、排除列 12 列。`PPI_LEN` 之外的列不得由动态列选择逻辑自动传入模型。

## 可证伪的模型对照

1. ANN 序列与 SNN 接收相同 `PPI`、同一 `PPI_LEN` mask、同标签抽样、同周切分和同预算；参数量、更新 FLOPs 与状态字节逐项记录。
2. 流摘要 ANN 仅接收上表摘要特征，用于估计不依赖包顺序的参照。
3. SNN 包序列乱序对照只在每条 flow 内置换有效包，保持同一组事件值和同一 mask；若乱序不消除收益，不把结果归因于事件时序。
4. 所有标准化参数只由初始化期及此前已合法暴露的数据获得；本周未标注特征在预测前不得用于拟合本周归一化器。
5. APP/CATEGORY 标签编码不得依据 W19+ 的标签频次重排或合并；任何无标签低支持服务按协议的 `insufficient_evidence` 规则处理。

## 尚未验证

- 45 列白名单尚未接入模型 loader，也没有 ANN/SNN 输入一致性运行证据。
- 尚未审计匿名 `SRC_IP` 在不同周的稳定性；因为该字段排除出模型，主实验不依赖其分组功能，但重复 flow 或会话跨窗口仍需在不把标识暴露给模型的情况下评估。
- 尚未逐字段检验类别捷径强度；`DST_ASN`、`DST_PORT`、`TLS_JA3` 排除是预先的数据契约选择，不代表这些字段无信息。
- 完整流统计包含流结束后的量；结论仅适用于完整流分类，不外推为实时早期分类或网络控制效果。
