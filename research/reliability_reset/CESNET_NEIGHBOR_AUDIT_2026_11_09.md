# CESNET 多粒度网络遥测候选：近邻审计与裁决

日期：2026-11-09
范围：定向核对时间序列 Agent、通用数据 Agent、网络运维 Agent 与网络流量审计基准。不是系统综述；结论仅限本页列出的公开版本。

## 直接近邻矩阵

| 工作 | 实际测量对象与已覆盖机制 | 与 CESNET 候选的关系 | 仍未由当前公开材料证实的差异 |
|---|---|---|---|
| [TS-Skill](https://arxiv.org/abs/2605.24703) | 控制时间尺度选择、时间定位、跨区间整合三项时序分析技能；覆盖 Network Infrastructure 域 145 题；工具 Agent 在独立跨区间整合上有优势。基准为合成时序，作者指出可能未反映真实部署中的缺失和噪声。 | 直接覆盖本项目 T1–T3 所需的跨区间加总、平均与比较能力；网络域并非空白。 | CESNET 的稀疏 IP 级网络统计是否会改变模型相对强规则的错误结构或结论，尚未被本项目实测。仅把合成换成真实数据不够构成贡献。 |
| [TSAQA](https://arxiv.org/abs/2601.23204) | 210k 样本、13 个领域、6 类任务；核心分析题基于单序列 QA，但数据源包含多元异常检测等集合；核心序列过滤 missing rate >1%；作者把不规则采样、混合频率和动态分布列为局限。 | 覆盖广泛时序理解和分析；降低“真实数据/缺失数据 QA”本身的新颖性。 | 没有检索到其对 CESNET 式同一实体多聚合粒度、稀疏观测以及官方指标聚合契约的成对 Agent—规则实验。 |
| [TimeART](https://arxiv.org/abs/2601.13653) | 时序分析工具与 LLM 组成 Agent；构建 100k 工具轨迹，并在既有时序 QA 基准评测策略性工具调用。 | 直接覆盖“Agent 调工具算时序问题”的宽泛主张。 | 当前候选只剩网络遥测指标契约和稀疏实体结构的窄化交互；尚无 Agent 结果，也未证明它超出工具 QA 的常见聚合题。 |
| [Data Agent Benchmark (DAB)](https://arxiv.org/abs/2603.20576) | 54 个企业数据查询，覆盖 12 个数据集、9 个领域和 4 类数据库；评估跨库整合、转换和分析的端到端 Agent。 | 直接覆盖自然语言数据分析、异构来源和完整查询工作流。 | 网络协议统计语义及遥测删失能否改变运维归因，可能形成领域差异，但当前 CESNET 草题仅是字段查询/聚合，尚未体现该差异。 |
| [AgenticDataBench](https://arxiv.org/abs/2607.01647) | 15 个垂直领域的真实与生成式数据科学任务，使用细粒度技能标签和可执行评测。 | 广义数据 Agent 基准已非常广；仅增加一个领域或任务模板新颖性很弱。 | 需要证明网络故障/遥测链路的因果状态与输出责任具有特殊评测要求，并实证影响 Agent 判断。 |
| [NIKA](https://arxiv.org/abs/2512.16381) | 数百网络事件、5 类场景、54 类问题；30 多种诊断工具；记录 Agent 工具使用与查询时的网络真值，评估检测、定位和根因分析。 | 对“Agent 通过异构网络遥测诊断故障”是最直接的系统和任务近邻。 | 当前 NIKA 文献中没有发现与本项目完全同样的配对干预：保持初始 sink 缺行表现相同，分别操纵最后一跳真实丢包和 sink report 后续丢失，再以逐包账本裁定可识别性。但没有发现不等于证明首创。 |
| [CTBench](https://arxiv.org/abs/2608.12002) | 面向真实电信运维的故障根因分析与路径恢复任务；使用专家标注的黄金证据步骤，同时评估最终答案和诊断证据，并强调部分可观测与多厂商/设备/协议环境。 | 直接覆盖电信网络排障、证据质量和部分可观测；排除“证据约束的网络 RCA”作为独立宽泛主张。 | 当前公开摘要未显示对网络数据面末端丢包与 sink→collector 回执丢失做同条件、逐包真值配对；必须继续核对完整方法/数据，不能把该差异当新颖性证明。 |
| [FaulT-Bench](https://arxiv.org/abs/2608.27021) | 8 种网络拓扑中的 200 个排障场景，含真实故障、错误故障报告、错误设备归因及错误根因报告；复用 NIKA 工具接口。 | 直接覆盖不可靠网络报障核验与 Agent 在健康网络上的过度诊断；不能再把“验证错误报告”或“避免误报”作为主张。 | 公开摘要聚焦人类 ticket 的真实性，未显示同一 packet 的数据面转发与遥测回执通道配对注入；仍须复核公开任务/代码，不能视为已建立差异。 |
| [TelemetrySuffBench](https://arxiv.org/abs/2608.07899) | 以配对粗粒度视图、七类遥测遮罩和完全相同的歧义来源对照，分开测故障检测、来源定位与证据不足时的安全弃答；包含多模型与冻结盲测。 | 对“遥测不充分会妨碍根因定位”“Agent 应在证据不足时弃答”构成方法级直接近邻，即使其对象是 Agent 执行轨迹而非网络数据面。 | 候选差异只能落在具体通信网络故障/遥测链路因果配对及网络工具同信息规则，不是遥测充分性、来源定位或弃答机制本身；尚需完整近邻审计。 |
| [LossSight](https://doi.org/10.1109/TNSM.2021.3125012) / LB-LossSight | 对 INT 报告丢失进行检测、定位与恢复；LB-LossSight 研究多路径下的包丢失定位及每流/每出口标记计数。 | 直接覆盖 INT 报告缺失和数据面丢包定位；公平比较必须对齐双方可见测量能力。 | 已有源码级核对未发现论文展示“业务包到达 sink、仅其 UDP report 在 collector 前丢失”与“业务包在终末数据面丢失”的配对标签评估；这是有限文献观察，不证明其不能处理。 |
| [MeshAgent](https://doi.org/10.1145/3771567) | 三种网络管理应用中抽取并应用领域不变量，改善答案验证；报告可靠性指标，并支持低信心弃答。 | 覆盖网络 Agent 的领域约束、准确率提升及弃答/可靠性。 | 可能差异仅是以实验控制的网络观测删失为因果变量，而不是抽取领域不变量；当前没有独立运行证据。 |
| [WirelessBench](https://arxiv.org/abs/2603.21251) | 3,392 个无线网络智能任务；工具必要的 CQI 查询、多阶段移动决策、容差评分、灾难性错误和轨迹级错误定位。 | 直接覆盖通信 Agent 的工具链、多步决策和风险相关评分。 | 无线资源分配与数据中心/ISP 的 INT/collector 观测删失不同；但“网络工具 Agent + 风险评分”不可再作为贡献主张。 |
| [NetAgentBench](https://arxiv.org/abs/2604.09678) | 状态中心的多轮网络配置评测，FSM 保证确定性和有界执行；其形式化明确假设 perfect observability。 | 覆盖网络 Agent 多轮行为与确定性评分。 | 它的完全可观测假设与“工具证据可能因数据面或遥测面原因而删失”存在可检验差异；需要直接实验，而非仅比较设定文字。 |
| [ANT](https://arxiv.org/abs/2610.06514) | 从网络流量侧审计 Agent 行为：3,114 episodes、20 任务、5 场景，并标注风险/场景/行为原语。 | 名称与多粒度网络流量相似，但 Agent 是被审计对象，网络流量用于推断其行为；与本项目“Agent 读取遥测做运维诊断”的方向相反。 | 不宜把 ANT 当作同一任务；仍说明网络流量数据 + Agent 评测本身已有人研究。 |

## CESNET 方案裁决

### 已由数据证明

- 1,000 个高缺失 IP 序列的 545,302 个实体日中，三种体量计数均精确等于 10 分钟记录之和。
- CESNET 文档定义日级比例和平均值为已观测 10 分钟窗口的等权平均；本地全量复算与文档定义吻合，误差处于数值舍入范围。
- 违反该定义的流量加权统计会显著改变数值。这可以生成答案清楚的语义题，但任务仍是一般数据分析 Agent 可解的聚合题。

### 没有由数据证明

- 尚无模型/Agent 轨迹、Agent 相对 SQL/规则基线的差值、任务簇外推、评测排名改变或操作结论变化。
- 当前四个题目均由同一数据集、同一规则族构造，不能代表四个独立任务族。
- 公开基准已分别覆盖跨区间整合、时序工具使用、网络管理工具、容差风险评分和领域规则。当前项目尚未展示一项可改变这些基准结论的剩余测量问题。

### 决定

**NO-GO：不把“CESNET 多粒度网络遥测 Agent Benchmark”作为独立论文候选。**数据来源真实、复算一致和存在统计口径差异是工程/数据可行性证据，不等同于基准创新。该数据可留作网络 Agent 研究中的语义审计与后续外部验证素材；不扩成更大的模板题库，不调用模型 API，不把它登记成第二条主线。

**回归固定主线 NIKA 配对因果识别候选，保持 HOLD。**现有小拓扑配对的同信息端口计数规则已能分开两臂，尚无 Agent 增益。CTBench、FaulT-Bench、TelemetrySuffBench 和 LossSight/LB-LossSight 又分别覆盖电信网络证据诊断、不可靠故障票据、遥测充分性/来源定位及 INT 丢失处理；因此剩余问题只能是特定终末故障配对下、严格同信息预算规则无法解释的可复核差值。若完整近邻核对或冻结规则测试仍解释全部结果，则关闭该机制候选，长期研究方向不变。
