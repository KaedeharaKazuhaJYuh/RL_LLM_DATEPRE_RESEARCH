# 新候选的一页研究设计门槛

状态：**空白模板，当前未提出新候选**。以后只有具体候选出现时才填写；先完成并判断设计，再决定是否开发或执行。不要因普通的“继续”自动制造候选。

1. **原始契约**：固定基准、版本、任务、原成功定义和禁止的行为，附原文／任务证据；不增添原协议没有承诺的义务。
2. **源码依据**：指出确切的原生完整评分链及可能存在差异的环节，引用固定源码；区分辅助函数、任务专属检查和完整评分。
3. **已有合法可达性证据**：列出已存在的数据、权限、状态、工具操作或原轨迹来源，说明为什么无需修改原环境或契约即可到达。没有证据就写 unknown，不能以合成输入代替。
4. **具体预测与后果**：预测原完整评分为什么会放行、哪些其他原测试可能拒绝，明确预测并非已观察结果；给出对任务成功解释、系统选择或排序可能造成的具体影响，并逐项比较最近邻及强规则。
5. **否证条件**：列出哪些原生测试、不可达证据、契约解释或近邻结果会关闭假设；规定负对照和分母，不依靠删错样本或改变原分数。
6. **最低执行成本与决定**：列最少任务／轨迹、原生评分次数、模型 API 次数、依赖与预计耗时／费用；说明为何足以区分预测。记录 GO、NO-GO 或待证据及理由；关键信息缺失时不得直接开发或执行。

保留原始提案、失败和旧评分；不得把本地散列一致、单个合成控制或未复现的近邻论文结果表述为独立认证。用户后续明确指令可调整本门槛。
