# V5.0.15-beta.1 完成报告

本 beta 版本完成研究实现与审计基础，RL 训练矩阵现已可以使用 CUDA 执行。此前一次启动因运行环境暂时无法访问 NVIDIA 设备而停止；现在已确认 RTX 5070 Ti 和 `torch 2.9.1+cu128` 可用。训练矩阵目前尚未全部完成，因此暂不发布最终 beta 模型效果结论。

已完成的内容包括：

- 冻结 `tasks/v5/recovery_beta1` 协议。训练包含既有 16 个合成来源的 96 个任务；留出包含新下载的 UCI Auto MPG 和 Glass 两个来源、20 个任务、四类故障条件。归档 SHA-256、派生 CSV、许可和引用均写入 manifest。
- `RecoveryEnv` 支持真实 CSV 产物、一次提交回执、提交前超时、提交后确认丢失和部分写入。模型在检查前看不到故障标签；专家在全部留出任务和四种模式下通过。
- 完成五臂训练脚本：SFT、GRPO、branch、counterfactual、paired。counterfactual 枚举四个恢复动作并使用冻结行为策略后缀；paired 只在成对故障上下文共享随机流，便于检验故障干预是否有独立贡献。
- 完成三种子矩阵入口和一次性评测入口。评测从检查前状态开始，记录逐题动作、来源、任务族、故障、重复提交、检查次数和资源账本；训练矩阵全部结束前不会打开评测。
- 修复 GRPO 训练中采样温度与更新概率分布不一致的问题。采样现在明确使用 `top_p=1, top_k=0`，更新概率与相同温度缩放一致，并在摘要中记录分布。
- 修复原生滚动均值后端对布尔、浮点和非正窗口的输入校验；Go HTTP 请求现在拒绝尾随 JSON 值。

beta.1 时点的验证结果：恢复专家与分支隔离测试 6 项通过；版本检查、协议哈希检查和 Python 语法检查通过；Go 普通包测试通过；CUDA 可见性检查已通过。当时尚待 Go HTTP 回环重跑及完整训练评测。beta.2 收尾的最新验证与模型结论以 [beta.2 报告](V5_0_15_BETA_2.md)为准。

## CUDA 主机上的执行顺序

先运行完整训练矩阵：

```powershell
python -m experiments.v5_recovery_matrix --stage train
```

训练所有五臂、三种子成功后再运行留出矩阵：

```powershell
python -m experiments.v5_recovery_matrix --stage eval
```

评估完成后，以来源×任务族宏平均比较 paired、counterfactual、branch、GRPO 和 SFT；若未满足协议门槛，报告负结果，不调整留出任务或重新训练。
