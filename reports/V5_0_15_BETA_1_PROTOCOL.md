# V5.0.15-beta.1 恢复实验预注册（2026-10-08）

冻结于首次新模型训练和模型留出评测之前。实现阶段把此前大范围规划收敛为**给定正确首个操作和固定后续步骤的条件恢复试验**：策略只学习 inspect_commit / retry / continue / abort，不能将本轮成功率当作完整规划成功率，也不能与 V5.0.10 的 39/72 横比。新版宽泛 RL 改进目标继续保留，beta.1 首先完成查新报告提出的最小验证。

任务协议为 `tasks/v5/recovery_beta1`：训练来自既有 16 个合成来源、96 个任务；评测用此前未使用的 Auto MPG 与 Glass 两个 UCI CC BY 4.0 来源，20 个中英文任务×正常、提交前超时、提交后确认丢失、部分写入四条件=80 执行/种子。原文件及派生文件摘要、许可与引用在 manifest。两个新工具组合、部分写入条件和评测措辞只在留出使用。专家先全通过后才能运行模型。超时是事务边界的确定性注入，不是实际随机网络超时；文件和提交回执是真实持久产物。重复提交违反任务的一次提交契约，即使表格变换幂等仍判失败。

基础模型固定为本机 DeepSeek-R1-Distill-Qwen-1.5B BF16，每个种子使用其 V5.0.05 SFT control 适配器作为共同起点。以最后一个 token 的 A/B/C/D 四个 logits 定义归一化分类策略，训练采样与更新均用这一精确分布，评测取最大概率。属于约束动作接口下的真实 LoRA 神经网络训练，不是自由 JSON 生成。种子为 20260921/22/23，不通过留出选超参。

每臂 16 条件组×4 终局分支，最多 32 次优化器更新，学习率 2e-6、KL 系数 .02。每臂共用相同训练任务、正常/故障边际分布及给定检查后的中间状态；根节点准备调用、检查、所有分支调用和前向 token 分开计入账本。给定中间状态属于训练脚手架；测试从检查前起步。SFT 使用最多 32 次更新的强监督对照；RL 同分组跳过更新，因此实际更新数及 token 不相等，不称等 FLOP/等 token。

五臂：SFT 使用专家选择；GRPO 对完整采样后缀分配同组优势；branch 仅更新同状态分支的首动作；counterfactual 枚举四个首动作并采样冻结行为策略的后缀，使用四动作的期望奖励梯度；paired 与 counterfactual 相同，但成对故障分支采用共同随机数采样后缀。各故障条件独立计算优势，绝不混合不同观察。counterfactual/paired 是有限动作的一步策略改进近似，不冒称原 GRPO；后缀蒙特卡洛估计和两轮重用存在方差与近似误差。paired 的独立贡献必须对照 counterfactual，而不能归功于四动作枚举或更多监督。

确认门槛：paired 的来源×任务家族宏平均通过率分别高于 SFT、GRPO、branch、counterfactual，至少两种子净正，正常条件不低于 SFT；每来源单列，不用两个来源推断总体显著性。每个来源/任务家族下的语言和故障是相关重复。保留此前 +10 个百分点、全种子正等高目标，仅在上述门槛通过后考察；未过就报告负结果。全部训练完成才启动一次性模型评测，之后不改奖励、提示或权重。语义变换方向本轮只做契约与反例验证，不加入训练以避免归因混杂。
