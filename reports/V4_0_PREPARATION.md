# V4.0 初始准备

V4 已建立独立分支和预登记草案。主指标固定为经独立验证的端到端完成率；覆盖率、接受样本失败率、错误操作、升级、工具调用、延迟、token 与每成功任务成本必须共同报告。

训练、验证和最终测试将同时按数据来源、提示模板家族与故障家族隔离。最终测试集尚未创建，这是有意保留的盲测空间；在 V4 执行器、模型接口和阈值规则冻结前，不应生成并反复查看测试结果。

当前就绪检查不读取密钥内容，只检查 `DEEPSEEK_API_KEY` 或 `OPENAI_API_KEY` 是否存在。运行：

```text
python -m research.v4_readiness
```

当前下一道门槛是配置一个 API 提供商，然后实现所有工具都可中断的进程隔离执行环境。完成小规模成本试跑后，再确定三次以上重复实验的预算。
