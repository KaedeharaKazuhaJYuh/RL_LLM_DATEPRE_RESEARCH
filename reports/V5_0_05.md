# V5.0.05：两步课程监督对照与模型效果边界

日期：2026-09-29。按[预设方案](V5_0_05_SFT_CONTROL_PROTOCOL.md)，在同一个 DeepSeek-R1-Distill-Qwen-1.5B 本机基座及三个既有 SFT LoRA 起点上，补做两步课程的监督继续训练。结论是：**原 V5 beta.1 的 RL 策略没有超过这个监督对照**。本版保留完整负结果，不更换默认模型。

## 固定方法

训练只使用 `tasks/v5/beta_curriculum_v1` 的旧合成来源。每个种子复用原 GRPO 的 16 个任务与故障条件组，每组做 4 次专家回放，共 **64 个训练 episode、224 条动作决策样本**；导出器逐组核对原 RL 记录并要求专家完整通过。三个监督模型分别从种子 20260921、20260922、20260923 的原 SFT 适配器继续训练，而非重新初始化；按 RL 的 8、10、13 个真实更新组和 2 个 PPO epoch，设置 **16、20、26 次优化器更新**。BF16 GPU、学习率 `2e-6`、梯度累积 4、最大长度 768；不调用 DeepSeek API。

训练 episode 数和优化器更新数匹配，但监督标签来自专家，RL 数据来自随机策略执行；两者的实际 token 数、前向计算量和耗时不相等。本对照检验“采用两步课程进行监督继续训练”这一竞争性解释，不能单独证明严格等算力条件下哪种算法更优。训练导出摘要、适配器摘要、评测文件摘要与逐题动作序列记录在 [机器审计](v5_0_05_sft_control_audit.json)。

## 已见提示模板的来源留出结果

沿用 beta.1 已冻结的两份来源、12 道题和四种故障条件；每个种子 48 次执行。此集合在设计本对照前已经被使用过，因此本轮是**补充对照**，不是新的独立确认。

| 种子 | 原 SFT | 两步 SFT 对照 | 原 RL | 对照−原 SFT | RL−对照 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 20260921 | 36/48 | 36/48 | 34/48 | 0 | −2 |
| 20260922 | 34/48 | 37/48 | 36/48 | +3 | −1 |
| 20260923 | 26/48 | 34/48 | 32/48 | +8 | −2 |
| **合计** | **96/144** | **107/144** | **102/144** | **+11** | **−5** |

相对原 SFT，监督对照逐题新增 12、回退 1。相对监督对照，RL 只新增 1、回退 6，未达到预设的“RL 超过匹配监督对照”门槛。差距集中在 **类别规范化→计数** 组合：监督对照 33/48、RL 28/48；去重→滚动均值均为 48/48，截断→数值描述均为 26/48。按来源，Dry Bean 两者均 57/72，Letter Recognition 为监督 50/72、RL 45/72。失败动作中多次出现 RL 两步完成后继续调用工具，或故障后选择了不相关工具。

探索性任务簇 bootstrap（以 12 道题为簇，同时保留种子和故障记录）给出监督对照−原 SFT 的净变化 95% 区间 **[+2,+22]**，RL−监督对照为 **[−12,0]**。来源只有两份、题目相关性高，且对照集已被使用；这些区间只帮助描述不确定性，不作为新泛化或严格算法因果证明。

## 新措辞回归诊断

在此前用于选择两步课程的第一批新措辞题上，原 SFT 为 **12/144**、原 RL **11/144**、新监督对照 **10/144**；新对照逐种子为 4、4、2/48。该集合已参与研究决策，明确标记为[既有诊断集复测](v5_0_05_sft_control_novel_diagnostic.json)。三种策略绝对通过率都很低；两步课程在已见模板上的收益没有解决措辞迁移。

## 发布状态与下一步

本轮训练与评测在本机完成，三个新适配器和原始日志保存在 Git 忽略的 `work/v5_0_05_*`；公开仓库保留训练代码、预设方案、数据来源和机器审计，不能在缺少相同基座及适配器的机器上逐字节重放模型输出。V5.0.05 不更换默认策略，不把 107/144 当成独立外部效果，也不把 beta.1 的 +6/144 归因于 RL 算法本身。

下一轮应只在旧训练来源内加入新的同义改写与类别/故障恢复样本，先冻结**新的提示模板和第三批新来源**，再比较同预算 SFT 与 RL，并加入跨来源、跨模板的回退门槛。NPU 上的这些新权重尚未量化复测。
